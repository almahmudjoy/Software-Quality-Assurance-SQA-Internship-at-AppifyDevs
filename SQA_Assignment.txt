Assignment Requirements
1. Functional Testing

Prepare at least 30 functional test cases covering the application's core features.
Include: Test Case ID, Feature, Preconditions, Test Steps, Expected Result, Actual Result, and Status.
2. Bug Reporting

Identify and report a minimum of 10 genuine issues.
Each report should include:
Bug ID
Title
Description
Steps to Reproduce
Expected Result
Actual Result
Severity
Priority
Environment
Screenshot or Screen Recording
3. UI/UX Review

Provide at least 10 UI/UX improvement suggestions with supporting screenshots where applicable.
4. Exploratory Testing

Spend approximately 30–45 minutes performing exploratory testing.
Submit a brief report highlighting your observations, edge cases, and recommendations.
5. API Testing (Optional Bonus)

If APIs are accessible, perform basic API testing using tools such as Postman, Bruno, or Insomnia.
